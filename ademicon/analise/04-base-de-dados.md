# 04 — Como monetizar a base de dados (sem queimar e dentro da LGPD)

> **[PREENCHER]** Antes de agir, precisamos saber: de onde veio a base? Quantos contatos? Que dados tem (nome, telefone, e-mail, cidade, renda, profissão)? Qual foi a última interação? Com esses dados eu refino este plano.

## 1. Diagnóstico da base (checklist)
- [ ] Tamanho total e canais disponíveis (WhatsApp, e-mail, SMS).
- [ ] Origem (clientes antigos? leads de outro negócio? lista comprada?) → define a base legal (LGPD).
- [ ] Dados de segmentação: cidade/UF, idade, profissão, renda, se é PF/PJ.
- [ ] Data da última interação (base "fria" há anos se comporta como lead frio).
- [ ] Houve consentimento para contato de marketing?

## 2. Estratégia: aquecer antes de vender

**Nunca disparar oferta de consórcio para a base inteira.** O caminho:

1. **Higienizar**: remover inválidos, duplicados; validar WhatsApp.
2. **Segmentar** por persona provável (renda, profissão, região, PF/PJ).
3. **Primeiro contato = valor + opt-in**: conteúdo útil ou convite para uma ferramenta gratuita (simulador, planilha, live, workshop), com **opção de sair** clara.
4. **Quem interagir** → entra no funil de qualificação (WhatsApp) com consentimento registrado.
5. **Quem não interagir** → usar como **público personalizado** no Meta/Google (Custom Audience com hash) para anúncios — muito mais barato que falar 1:1 e sem invadir. Também gera **lookalike** para prospecção fria.

## 3. Canais para a base

| Canal | Uso | Cuidado |
|---|---|---|
| E-mail | Newsletter educativa, convites | Baixo risco, baixa conversão; aquece |
| Custom Audience (Meta/Google) | Anúncios de isca para quem já te conhece | Precisa de base legal; é o uso mais escalável |
| WhatsApp API oficial | Mensagens com template aprovado e opt-out | Evitar número pessoal para disparo (bloqueio) |
| SMS | Convite curto para ferramenta | Opt-out obrigatório |
| Ligação | Só para segmentos quentes | Respeitar "não perturbe" |

## 4. Outras formas de monetizar a base (além de vender cota)
- **Cross-sell de produtos Ademicon**: seguros, home equity (**[CONFIRMAR quais produtos o consultor pode vender e comissão]**).
- **Parceiros**: encaminhar leads de imóvel para corretores parceiros (e vice-versa), com regras claras e consentimento.
- **Evento/live** para a base: "Como comprar seu imóvel sem pagar juros para banco" → gera lista de interessados.

## 5. Métricas
- Taxa de entrega, resposta, opt-out, lead qualificado, reunião, venda **por segmento**.
- Se opt-out > 2–3% numa mensagem → mensagem errada ou segmento errado; parar e ajustar.
