# 04 — Como monetizar a base de dados (sem queimar a base)

> **[PREENCHER]** Antes de agir, precisamos saber: de onde veio a base? Quantos contatos? Que dados tem (nome, telefone, e-mail, cidade, renda, profissão)? Qual foi a última interação? Com esses dados eu refino este plano.

## 1. Diagnóstico da base (checklist)
- [ ] Tamanho total e canais disponíveis (WhatsApp, e-mail, SMS).
- [ ] Origem (clientes antigos? leads de outro negócio? lista comprada?) → define o nível de "calor" e o tipo de abordagem.
- [ ] Dados de segmentação: cidade/UF, idade, profissão, renda, se é PF/PJ.
- [ ] Data da última interação (base "fria" há anos se comporta como lead frio).
- [ ] Essas pessoas já receberam mensagens suas antes (reconhecem seu nome/marca)?

## 2. Estratégia: aquecer antes de vender

**Nunca disparar oferta de consórcio para a base inteira.** O caminho:

1. **Higienizar**: remover inválidos, duplicados; validar WhatsApp.
2. **Segmentar** por persona provável (renda, profissão, região, PF/PJ).
3. **Primeiro contato = valor**: conteúdo útil ou convite para uma ferramenta gratuita (simulador, planilha, live, workshop). Quem levanta a mão já chega pré-vendido.
4. **Quem interagir** → entra no funil de qualificação (WhatsApp).
5. **Quem não interagir** → usar como **público personalizado** no Meta/Google (Custom Audience com hash) para anúncios — muito mais barato que falar 1:1. Também gera **lookalike** para prospecção fria.

## 3. Canais para a base

| Canal | Uso | Cuidado |
|---|---|---|
| E-mail | Newsletter educativa, convites | Baixo risco, baixa conversão; aquece |
| Custom Audience (Meta/Google) | Anúncios de isca para quem já te conhece | O uso mais escalável; também gera lookalike |
| WhatsApp API oficial | Disparo em escala com template aprovado | Nunca disparar em massa do número pessoal: o WhatsApp bloqueia |
| SMS | Convite curto para ferramenta | Barato, taxa de clique baixa |
| Ligação | Só para segmentos quentes/alto ticket | Converte mais, custa tempo |

## 4. Outras formas de monetizar a base (além de vender cota)
- **Cross-sell de produtos Ademicon**: seguros, home equity (**[CONFIRMAR quais produtos o consultor pode vender e comissão]**).
- **Parceiros**: encaminhar leads de imóvel para corretores parceiros (e vice-versa), com divisão de comissão combinada.
- **Evento/live** para a base: "Como comprar seu imóvel sem pagar juros para banco" → gera lista de interessados.

## 5. Métricas
- Taxa de entrega, resposta, pedidos para sair, lead qualificado, reunião, venda **por segmento**.
- Se mais de 2–3% pedirem para sair ou bloquearem numa mensagem → mensagem errada ou segmento errado; parar e ajustar.
