# Base de análise de VSL e copy (Google Drive) — índice

> O acervo de VSL/copy está no **Google Drive** (o repositório "Claude" não está acessível no GitHub). Aqui fica o índice com os IDs dos arquivos e os frameworks resumidos, para qualquer chat consultar.

## Frameworks (resumo)
| Framework | Estrutura |
|---|---|
| **9 vendas da VSL** | Atenção (headline + lead) → Visualização → Credibilidade → Problema → Solução → Valor → Segurança → Conveniência → "Faça agora" |
| **Stefan Georgi (RMBC)** | Lead (problema + promessa + pista do mecanismo contraintuitivo + qualificação) → história de fundo → **mecanismo único do problema** → **mecanismo único da solução** → criação do produto → fechamento (alternativas, custo da inação, CTA, garantia, duas escolhas) |
| **Jon Benson** | Quebra de padrão + "vamos fazer um acordo?" → grande conexão (herói) → grande problema + **vilão** + "a culpa não é sua" → grande solução → grande oferta (objeções, ancoragem, CTA, dois cenários) |
| **Leandro Ladeira (VVV)** | Promessa com QFD (quê/forma/dor) → pra quem é → prova → história → conteúdo (jeito comum × jeito certo contraintuitivo) → oferta → CTA emocional |
| **PAS / P.A.S.T.O.R. / AIDA / Russell Brunson** | Problema-agitação-solução; epiphany bridge; stack de oferta |
| **Método Russo** | Espelhar uma VSL **validada** de outro nicho mantendo estrutura e ritmo, trocando só o conteúdo. Métricas: play rate > 60%, retenção no pitch > 40% |
| **Prompt de análise (Aula 9)** | Mecanismo oculto do problema · mecanismo da solução · autoridades · persona (dores emocionais, financeiras, físicas) · gatilhos · tom · palavras-chave para Google Ads · 5 frases para headline · clusters semânticos |
